# Exemplo: INside 2026 (Construct IN)

Caso real que originou o squad. Dois decks para o telão LED do evento:

- `ppt1-equacao-da-gestao.html` — abertura com logo, equação da gestão se montando, holofote em Relato, Referência (painel "o que deveria acontecer") e Evidência (cards com mídia real)
- `ppt2-produto-visi.html` — abertura, 5 slides de feature com espaço para vídeo/GIF, equação com foco em evidência

Este exemplo usa o motor direto de `../../templates/engine/` para acompanhar as melhorias do squad.
Num projeto real, `scripts/new_deck.py` copia o motor para `assets/` e a pasta fica autocontida.

Mídias esperadas em `media/`: `evidencia-360`, `evidencia-drone`, `evidencia-nuvem-de-pontos`,
`01-nuvem-de-pontos`, `02-sobreposicao-de-projetos`, `03-volumetria`, `04-angulo-drone-360`, `05-captura-por-video`.

Logos e identidade pertencem à Construct IN; usados aqui só como referência de trabalho.
